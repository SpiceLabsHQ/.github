# Spice Labs

Software should have flavor.

Most software works. It loads, it runs, it does the thing. But somewhere along the way, the industry decided that *functional* was good enough. We disagree. We come from design and business, not just engineering — so we think about how something looks, how it feels, and whether it solves a problem worth solving before we write a line of code. The details that most teams skip? That's where we live. It turns out the best software comes from people who understand the user, the market, and the pixels.

We build websites, web applications, serverless functions, and CLI tools across industries. AI is a great ingredient, but it's not the whole dish. Trends come and go. Craft doesn't. What matters is the end result: software that's elegant, useful, and feels like someone actually cared.

## How We Think and Work

We believe the tools you use shape how you think. A clunky tool teaches you to work around problems. A good one teaches you to see them differently. That's the bar — not just "does it work," but "does it make the person using it *better* at what they do?" We're opinionated by design. We'd rather build something specific and excellent than generic and forgettable. Every decision has a reason, every default is intentional, and if something feels a certain way, it's because we wanted it to.

TDD-first. SOLID principles. Quality gates that actually block bad code, not just warn about it. We write tests before we write features, not because a process told us to, but because it's how you build things you can trust. If we wouldn't ship it for a client, we won't ship it at all.

## Open Source

Most of what we cook up stays in the kitchen. We work across industries on projects we can't talk about, and that's by design. But the tools we build along the way — the ones that make *our* dev experience better — we open source those. If they help us, they'll probably help you too.

**[Claude Marketplace](https://github.com/SpiceLabsHQ/Claude-Marketplace)** — Our plugin registry for Claude Code. We got tired of watching AI stumble through complex workflows without guardrails, so we built opinionated plugins that teach Claude how to coordinate like a professional. Every plugin has strong opinions about how work should get done, because we've already made the mistakes so you don't have to.

**[Reaper](https://github.com/SpiceLabsHQ/Reaper)** — Our first marketplace plugin, and the one we use every day. Ground control for your codebase — coordinating specialized agents for planning, development, review, and security with automatic quality gates between each stage. Approve the plan, grab a coffee, come back to finished work. It's how we build everything, and now you can too.
